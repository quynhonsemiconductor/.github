# Code of Conduct

## Our commitment

QNSC (Quy Nhon Semiconductor) is committed to providing a respectful,
harassment-free environment for everyone who contributes to or interacts
with our repositories — employees, contractors, and approved partners alike.

This applies across all QNSC-VN organization repositories, issues, pull
requests, code review, and any other project space (chat, email, meetings)
tied to this work.

## Expected behavior

- Be respectful and professional in all communication, especially in code
  review and issue discussions.
- Give and accept constructive feedback gracefully — critique the code and
  the approach, not the person.
- Be considerate of differing viewpoints, experience levels, and working
  styles across a distributed, multi-timezone team.
- Respect confidentiality — QNSC repositories contain proprietary and, in
  some projects, export-controlled (ITAR/EAR) or PHI/HIPAA-class information.
  Only access and discuss what your role authorizes.

## Unacceptable behavior

- Harassment, discriminatory jokes or language, or personal attacks in any
  QNSC space.
- Publishing others' private information without explicit permission.
- Deliberately submitting insecure, malicious, or destructive code.
- Circumventing access controls, review requirements, or security policy for
  convenience.
- Any conduct that would be inappropriate in a professional workplace.

## Reporting

If you experience or witness unacceptable behavior, report it to:

- ✉️ **Email** — `info@qnsc.vn` (or your manager / team lead directly)

Reports are handled confidentially. We will investigate promptly and take
appropriate action, which may include a warning, removal from a project or
repository, or termination of contract/employment, depending on severity.

For security vulnerabilities (as opposed to conduct issues), use the process
in [`SECURITY.md`](./SECURITY.md) instead — do not mix the two.

## Scope

This Code of Conduct applies to all QNSC-VN GitHub repositories and any
associated project communication channels, whether the interaction happens
during work hours or not, whenever it relates to QNSC work.
